# STEP ionosphere regression fixture

`STEP_20260917_iono.jps` contains five unchanged CRC-valid IO frames from
`gnss/raw/step_17049/step/astep0917l.jps` and `astep0917m.jps` in
`original-stage-us-east-2-99umu5ol0qe7`, downloaded September 17, 2026.
The four distinct time-of-week payloads from l plus the 813694980-second
payload from m demonstrate valid IO records interspersed with malformed
time fields. Total 220 bytes; SHA-256
`93513b9a695e02d506d647c15a41ddb189abce77a010def7b5ec5d97f0bbff45`.

Extraction uses the CRC-checking GREIS ReadFrame, then copies original
frame bytes. Version/head/tag evidence is retained in the git-ignored
`docs/context/local/sbf-parity/batch-errors/` directory. Values 0xfffffffd
and 813694980 exceed seconds per week; they are not treated as a
vendor-documented sentinel or repaired to an invented timestamp.
